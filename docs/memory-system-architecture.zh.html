参考架构 · 脱敏展示版

让记忆持久，但别把上下文变成杂物抽屉。

一套以 provenance 为核心的分层方法：原始证据长期保存，派生索引随时可重建，日常只召回最小充分上下文；只有 curated memory 不够时，才按需恢复原始来源。

Share the method. Protect the memory.
Durable保留 source identity、时间、fidelity 与 provenance。
Rebuildablechunks、projections、rankings 与 caches 都允许推翻重建。
Scoped只加载足以支持当前回答的最小上下文。
Explainable每条被召回的信息都能沿路径回到证据。

Cold retrieval 是证据升级，不是第二套默认搜索

Raw catalog 像仓库索引卡：它告诉系统箱子在哪里、封条是否完整，但不会把箱内对话摊进普通 recall。

1

Locate · 定位

使用已知 source ID、时间范围或 curated Session link，把目标缩小到一个或极少量 raw records。

2

Verify · 校验

检查路径边界、文件权限、byte size、cryptographic hash、record count、source identity 与 timestamps。

3

Rehydrate · 最小恢复

区分 visible dialogue、system context、reasoning 与 tool records，只恢复当前问题真正需要的内容。

清楚的 ownership 能避免 memory corruption

每一层只做一件窄而明确的事；方便的派生层永远不能比它的 source 更权威。

POLICY

Operating rules

当前安全、检索、隐私和协作规则。历史内容不能把自己提升成这一层的新指令。

SOURCE

Curated archive

Canonical Sessions、复核事实、有日期的 state、decision history 与 source links，用于日常 evidence-backed recall。

DEEP SOURCE

Raw cold storage

原始来源副本与 metadata-only locator。私密、默认关闭，只在 targeted recovery 时读取。

DERIVED

Retrieval and context

Chunks、aliases、state projections、scores、traces 与 context packets；可观察、可替换、可重建。

时间是证据，不是固定 TTL

不同事实的变化速度不同；预期复查点已过，不等于系统有证据证明状态已经反转。

OBSERVE

observed_at

记录观察发生的时间；它回答“我们什么时候看到这个状态”，不是自动失效计时器。

VALIDITY

valid_from / valid_to

只保存真正已知的适用区间。终点未知时保持为空，不用猜测性的 TTL 补齐。

CONFIRM

last_confirmed_at

记录同一状态最近一次明确确认；collection 的 reviewed_at 不能代替事实确认。

CHECKPOINT

expected_resolution_at

表示预计复查或获得结果的日期。超过它只添加可见提示，不静默改写状态。

◷

可测试规则：注入 as_of；基础排名保持不变，只在 checkpoint 已过且没有后续确认时附加解释性时间标签。

证据升级工作流

问题需要走多远，就只升级到多远。

信号第一步何时升级边界
当前上下文足够不检索，直接回答无需升级不要养成顺手翻私人历史的习惯。
明确依赖过去内容运行 curated retrievalPacket 缺少精确证据或 provenance。使用简洁 intent，不照抄整段用户消息。
需要原话、顺序或理由搜索 private curated archive最佳 surviving curated source 仍然不完整。摘要不能当作逐字对话。
必须恢复一个已知来源先查 raw catalog，再做验证仅在目标已经缩小以后。不默认扫描或整库加载 raw storage。
问题缺少可用锚点问一个最小澄清问题用户补充 source、event、entity 或时间锚点。不要猜用户指的是哪段私人历史。

把必须全绿与用于发现问题的 suite 分开

测试失败的含义必须清楚；异构 ranker 的 raw score 也不能被假装成统一概率。

Lane用途运行语义晋升规则
Regression保护已经承诺的行为正常运行必须全绿只接收已经修复并稳定的 case
Challenge / probe保存真实 miss 与人工 contrast允许显式报告已知失败修复后再进入 regression
STRONG

provenance_supported

候选具有 canonical source link 或明确 provenance；这是证据形状标签，不是置信概率。

CONTEXT

structured_context

Topic、entity、state 或 decision 字段提供支持，适合解释为什么被召回。

WEAK

lexical_only

只有措辞重合，没有更强结构信号；应测量是否造成 forbidden hit 或 packet 污染。

TRIAGE

SKIP miss ownership

先归上层语义 triage；从少量人工 contrast 和真实漏检开始，不自动生成海量无语境查询。

Fidelity 本身也是回答的一部分

优先使用最强的 surviving evidence，同时诚实标注被转换和整理过的材料。

Visible transcript直接对话
Transcript snapshot保留下来的 export
Hybrid recordsource + curation
Structured summary定位与恢复辅助
Derived projectionlocator，不是 source

一句话模型：Archive 记住发生过什么；Retrieval 决定现在该想起什么；Raw Catalog 知道证据箱在哪里；Policy 决定助手当前可以做什么。
