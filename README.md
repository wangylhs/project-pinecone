# Project Pinecone

*Small seeds. Durable memory. A forest of context.*

Project Pinecone is a small, provenance-first home for experiments around durable memory, retrieval, and context.

## First seed

[`index.html`](./index.html) is a standalone visual map of the current local memory system: its data flow, storage boundaries, directory structure, and ownership model.

No build step or external dependencies are required. Open `index.html` directly in a browser.

## Status

Seed stage. Keep it small, inspectable, and easy to rebuild.
